パスワード管理ノートを印刷して作る

「印刷する」を押すだけ。画面には何も打ち込みません。お店で売り切れのときにも使えます。

  1. 印刷する下の「印刷する」を押します。A4の紙に、たて向きで。
  2. 手で書くメール・銀行・買い物の順に。こすると消えるペンは使いません。
  3. 家にしまう通帳と同じ場所へ。持ち歩かず、ほかの人の目にふれない所に。

新しいパスワードを作る

この文字をサービスの「パスワードの変更」で入れて、同じものをノートに書き写します。見分けにくい文字（0と1、l・I・O）は入っていません。保存も送信もしません。長さや形を選ぶならパスワードを作るへ。

紙に書くときの考え方（読みたい方へ）
  • いちばん大事なのは、使い回さないこと。同じパスワードをあちこちで使うくらいなら、紙に手で書いてでも、サービスごとに別のものにするほうが安全です。
  • 紙が向いている人。パソコンやスマホの操作が苦手な方、年配の方、管理アプリがむずかしいと感じる方です。家族のぶんを作ってあげるのにも使えます。
  • 家に置いて、外に持ち出さない。かばんに入れて持ち歩くと、なくしたり、開いた所を見られたりします。
  • ほかの人の目にふれない所にしまう。来客や、家に出入りする人から見えない場所へ。机の上やパソコンの横に出したままにしません。
  • 件数が増えてきたら、管理アプリも。なくしても戻せて、偽サイトにも気づきやすくなります。無料のものと有料のものの違いは管理アプリのページにあります。紙のままで足りている方は、そのままで大丈夫です。
くわしく読む：紙のノートでパスワードを守るコツ（3分で読めます）

結論から言うと、パスワードを紙に書いて管理するのは、家で保管するなら公的機関も挙げている方法です。守ることは3つだけ。①サービスごとに別のパスワードにする ②家の決まった場所にしまい、持ち歩かない ③大事なサービスには2段階認証を付ける。

「紙に書いて本当に大丈夫？」「どこにしまえばいい？」「いつ変えればいい？」が気になる方に向けて、理由と出どころを添えてまとめました。読みたい所だけでも大丈夫です。

1. 紙に書いても大丈夫？ → 家で保管するなら大丈夫

大丈夫です。家で保管するノートは、公的機関も挙げている方法です。

理由は、紙はネットにつながっていないので、ネット越しに盗まれないからです。IPA（情報処理推進機構）は、覚えきれない場合の方法として「自宅で保管するノート等」への記録や、パスワード管理ソフトの利用を勧めています。

いちばん避けたいのは、同じパスワードをあちこちで使い回すことです。使い回すくらいなら、紙に手で書いてでも、サービスごとに別のものにするほうが安全です。

2. どこにしまう？ → 家の、鍵のかかる所

家の決まった場所にしまい、持ち歩きません。通帳や保険の書類と同じ場所が分かりやすいです。

理由は、紙の弱い所が「なくす」と「見られる」だからです。総務省は、メモに書いた場合は「鍵のかかる机や金庫など安全な方法で保管すること」としています。

  • 端末や机に貼らない。IPAも総務省も、パスワードのメモを貼らないよう求めています。端末をなくすと、そのまま入られます。
  • かばんに入れて持ち歩かない。かばんごとなくしたり、外で開いた所を見られたりします。
  • ほかの人の目にふれない所に。来客や、家に出入りする人から見えない場所へしまいます。

3. どれから直す？ → お金のサービスから

全部をいっぺんに直さなくて大丈夫です。お金と、ほかの入口になるものから順に進めます。

  1. 銀行・証券・クレジットカード
  2. Apple や Google のアカウント
  3. メール
  4. よく使う通販

メールやアカウントを早めに直すのは、ほかのサービスのパスワードを作り直す入口になるからです。今日は銀行だけ、次はメールだけ、という進め方で十分です。新しいパスワードは、このページの「新しいパスワードを作る」で出せます。

4. いつ変える？ → 定期的には変えなくていい

決まった時期ごとに変える必要はありません。変えるのは、流出の知らせが来たときと、使い回していたときです。

総務省の一般向けページは、サービスの側から流出した事実がない場合は「パスワードを変更する必要はありません」とし、それよりも使い回しのない固有のパスワードにすることを求めています。

変えたら、ノートの古いパスワードに線を引いて、「変えた日」と「新：」の欄に書き足します。欄がいっぱいになったら、新しい枠に書き写します。

5. ほかに気をつけることは？ → 2段階認証と、画面のロック

大事なサービスには2段階認証を付け、席をはなれるときは画面をロックします。

大きな会社からの流出は、自分では防げません。「もう漏れているかもしれない」と考えて、漏れても広がらない形にしておきます。2段階認証があれば、パスワードが知られても、それだけでは入れません。付け方はサービスごとの一覧にあります。

画面のロックは、すぐロックするキーを覚えると楽です。Windows は「Windows ロゴ キー ＋ L」、Mac は「control ＋ command ＋ Q」です。買い物サイトなどを、使うたびにログアウトする必要はありません（家族と共用のパソコンは別です）。

6. 紙で足りなくなったら？ → 管理アプリへ

書く件数が増えて大変になったら、パスワード管理アプリが向いています。なくしても別の端末から戻せて、本物のサイトでしか自動で入力されないので、偽サイトにも気づきやすくなります。

管理アプリを使う場合も、紙に残すものが1つだけあります。もしもの時に戻すための復旧用のコードです。印刷して、家の鍵のかかる所にしまいます。アプリを開くためのパスワードは頭で覚え、クラウドのメモや写真には置きません。くわしくは管理アプリのページにあります。

まとめと、次にやること

  • 紙のノートは、家で保管するなら大丈夫
  • サービスごとに別のパスワードにして、使い回さない
  • 家の鍵のかかる所にしまい、貼らない・持ち歩かない
  • 定期的には変えない。流出の知らせが来たら変えて、ノートに書き足す
  • しまってある場所だけを、信頼できる家族1人に伝えておく

次にやること：下の「印刷する」で用紙を出して、まず銀行とメールの2つから書いてみてください。

よくある質問

パスワードを紙に書いても大丈夫ですか？

家で保管するなら、公的機関も挙げている方法です。IPA（情報処理推進機構）は、覚えきれない場合は自宅で保管するノートなどへの記録や、パスワード管理ソフトの利用を勧めています。総務省は、メモに書いた場合は鍵のかかる机や金庫など安全な方法で保管するよう求めています。端末や机に貼るのは避けてください。

このページにパスワードを入力するのですか？

入力しません。このページが作るのは白紙の用紙だけで、文字を打ち込む欄はありません。印刷したあと、手で書きます。選んだ件数や欄も、保存も送信もしません。

パスワードを変えたときは、どう書きますか？

「変更の履歴」の欄に、変えた日と新しいパスワードを書き足します。古いものは線で消すと、どれが今のものか分かります。欄がいっぱいになったら、新しい枠に書き写してください。
